This is a template project. Each project lives in its own Markdown file inside
`src/projects/`, with frontmatter at the top (between the `---` lines) and a
description written in Markdown below.

- `title`, `date`, and `lead` are required.
- `repo` (`owner/name`) is used to fetch the GitHub star count and link.
- `topics` become the little tag pills.
- `image` points to a file in the same `src/projects/` folder.
- Optional: `image_border`, `image_rounded`, and `subimages: [...]`.

To add your own project, copy this file, rename it, drop an image next to it,
and edit the content. To remove the placeholder, just delete this file and
`example-project.svg`.
